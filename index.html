はる / Haru

小説家志望 / Fiction Writer

日常と非日常の境界を歩く物語を書いています。

About

現代の青春、すこしだけずれた現実、そして「優しい世界の中の残酷さ」。
そういった境界の空気を持つ物語を書くのが好きです。
心の揺れや孤独、再生の瞬間を、静かでやわらかな文体で描くことを大切にしています。

Works

  • 刺青といちご 短編

    夜の水槽のような街で、刺青を入れる少女と出会う少年の物語。 痛みと救済が入り混じる青春の一夜を描く短編。

    ジャンル：青春 / 片恋 / 静かなドラマ
    状態：完成

  • 銃男 短編

    「朝起きたら右腕が銃になっていた」少年の物語。 異能と日常の境界を、文学寄りのタッチで描いた作品。

    ジャンル：スリップストリーム / 自己喪失
    状態：完成

  • 幸福のカレー 短編

    家族の崩壊と、その中で一皿のカレーがもたらす“幸福の記憶”を描いた作品。 悲しみの底から少しだけ世界が明るくなる、静かな再生の物語。

    ジャンル：家族 / 再生 / 日常系
    状態：完成

  • 未来の恋人 短編（草稿）

    「私は未来から来た、あなたの恋人です」と名乗る女性が現れる短編SF。 原稿用紙8枚まで執筆済み。時間のねじれと喪失、恋のはじまりを描く。

    ジャンル：SF / 恋愛 / 日常のズレ
    状態：草稿
